# Orações — Um momento com Deus

Aplicativo web responsivo de orações em português, criado para uso no celular e computador.

## Recursos

- Oração do dia
- Orações de manhã, noite, família, saúde e cuidado, agradecimento e momentos de ansiedade
- Leitura confortável em celular
- Ouvir oração usando a voz disponível no dispositivo
- Favoritos salvos no navegador
- Alternância entre tema escuro e claro
- PWA/instalação como aplicativo
- Sem dependências externas obrigatórias

## Publicação

Este projeto foi preparado para ser publicado pelo GitHub Pages. No repositório GitHub, abra **Settings → Pages**, selecione **Deploy from a branch**, escolha `main` e a pasta `/ (root)` e salve.

Depois da publicação, o GitHub Pages fornecerá o endereço público do aplicativo.

## Personalização do fundo

O layout está preparado para receber a imagem de fundo enviada pelo proprietário do projeto. Para adicioná-la, coloque o arquivo na raiz ou em `assets/` e ajuste o fundo da classe `.hero` em `style.css`.

## Tecnologias

HTML5, CSS3 e JavaScript puro.
